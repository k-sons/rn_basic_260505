#전부 큼포저2로함 다시 지피티5.5   점검받음
앱이 하는 일

React Native + Expo(Expo Router)로 만든 날짜별 “사진 1장 + 짧은 메모” 일기 앱.
메인에서 날짜 카드 + 좌우 스와이프로 날짜 이동, **이 날짜 편집**으로 사진/메모 저장.
저장은 날짜 키 YYYY-MM-DD당 1개 구조(같은 날은 덮어쓰기).
목록 탭으로 작성한 날짜 보고 해당 날로 점프, 백업·복원 화면으로 JSON 처리.
기술·동작

expo-image, expo-image-picker, 제스처/리애니메이션, 로컬 저장(AsyncStorage + 포맷 v2 + 웹은 IndexedDB/압축 등), Android 권한·이미지 리사이즈 등이 대화 속에서 언급됨.
이후 대화로 웹 이미지 contain, 메인 세로 스크롤, 웹 삭제는 window.confirm, 웹은 JSON 파일 선택 가져오기, Expo Go는 클립보드 복사(expo-clipboard) 같은 보완까지 이어짐.
